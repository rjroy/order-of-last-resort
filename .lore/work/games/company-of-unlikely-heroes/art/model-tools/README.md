# Non-hero authoring and review tools

The [accepted roster](../concepts/non-hero-cast/accepted-roster.md) selects the exact standalone Blender files. Each model opens without a sibling or any review script. Shared historical group tools live here, rather than inside one member's package:

| Directory | Purpose |
| --- | --- |
| `oddkin/` | Goblin, Village Troll, Ogre and Trickster pose and motion studies. |
| `bandits/` | Fierce, Guard and Swift Bandit authoring and group review. |
| `rivals/` | Mirror Company pose and motion studies. |
| `field/` | Sheep and Opposing Shepherd studies. |
| `wagon/` | Last Wagon shared fabrication, read-only checks and visual studies. |
| `review_accepted.py` | Read-only reopen/check or render Ready and signature poses from the accepted roster. |

The group tools reproduce the respective development studies, not their common-finish presentation. They stay separate from the shared cast baker and cannot publish runtime assets. Hookhand's optional reconstruction reuses the earlier Harpooner authoring scripts; the approved Hookhand `.blend` is self-contained.
