# Cast cue integration

An authored character can opt into the packaged cast with `cast_key` and `cast_art_key` in its **character** record. `cast_key` identifies the animated actor independently of legacy `art_key`. `cast_art_key` must match the effective legacy art key; a different key or a nonempty `art_variant` keeps the custom art. A class does not pass down cast opt-in. Missing sprite art falls back to the existing figure. The clip mapping checks the ability's handler and, where a handler covers unlike actions, the relevant parameters. Reusing a stock ability ID for a different mechanic does not play its stock action clip.

Rules still uses the same ordered event log for forecasts and outcomes. On a successful action, the first existing event carries `resolved_action` with the acting instance ID, ability ID, actor cells before and after, and `event_count` (including that first event). Repeat Batch also records its bottled recipe ID before it is consumed, so presentation follows the original dose rather than reaction polarity. This group includes the action's primary effects and side effects, but not later objective narration. The metadata distinguishes the actual caster from other event sources, such as a Knight who absorbs an attack. It is not a new event, and does not change log text, state, rolls, or order.

Only a successful commit sends cues to the renderer. Each supported resolved action produces one cue with `unit_id`, `cast_key`, `clip`, `source_cell`, `actor_cell`, `target_id` (empty when not directed at an entity), an optional `target_cell`, and `recipients` (`id`, `cell`, `kind`). Cells are from the time of the action, not the round's final positions. A strike's target is its actual contact recipient; a completely absorbed strike aims at the ward without showing damage. Heal feedback identifies only the characters who regained HP. Don't Go and Wasn't Me mark the affected character with neutral status feedback. Dry Bard performances still animate without a recipient. Reactions, bonus events, and secondary hits are not separate action performances. The Zombie's gift and Mixologist's acid flask launch at their manifest release markers toward the resolved target; neither resolves a second attack.

Mission settlement never waits for animation. When an outing leaves battle, a short, input-transparent replay inset may retain the outgoing board. Pressing a key or clicking dismisses it without consuming the input. It also clears when playback finishes, the page changes, or 3.2 seconds elapse. A standalone terminal round plays on its existing board; restarting clears playback.
